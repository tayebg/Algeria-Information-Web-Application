# Interactive Map of Algeria

An interactive web application showcasing the 58 provinces (wilayas) of Algeria with an immersive cinematic video experience.

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Framer Motion
